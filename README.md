## Machine-learning project

**Smartwatch-based glucose risk classification:** an exploratory project using smartwatch data to identify possible hyperglycemia and hypoglycemia risk. I trained a **Random Forest** model with **scikit-learn** and used **Django** for the web application.

I evaluated the imbalanced classification problem using **precision, recall, F1-score and a confusion matrix**. This project is exploratory and does not establish clinical validation or direct glucose measurement.
